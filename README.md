JavaScript Basic Operations

About

This is a simple JavaScript project. I made this project to practice using variables, loops, conditional statements, and basic mathematical operations in JavaScript.

The program performs different operations such as finding the sum of natural numbers, printing a multiplication table, checking whether a number is prime, finding factors, finding the sum of digits, and checking whether a number is an Armstrong number.

Operations Performed

1. Sum of Natural Numbers

Finds the sum of natural numbers up to a given number using a for loop.

2. Multiplication Table

Prints the multiplication table of a given number.

3. Prime Number Check

Checks whether a given number is prime or not using a loop and conditional statement.

4. Factors of a Number

Finds and displays all the factors of a given number.

5. Sum of Digits

Finds the sum of all digits of a given number using a while loop.

6. Armstrong Number Check

Checks whether a given number is an Armstrong number or not.
